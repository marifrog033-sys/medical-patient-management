# Система ведения пациентов

Консольное Python-приложение для работы с данными пациентов, историей посещений и расписанием приёма.

## Возможности

- хранение данных пациента в формате JSON;
- хранение истории посещений в TXT-файлах;
- работа с расписанием приёма в формате CSV;
- просмотр предыдущих посещений;
- просмотр записи конкретного посещения;
- создание записи текущего посещения;
- автоматическое изменение статуса посещения;
- интерактивное консольное меню.

## Технологии

- Python 3
- JSON
- CSV
- работа с файловой системой
- `tabulate`
